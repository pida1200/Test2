Proveď multi-agent krok na GitHub issue zadaném za `/m` (např. `/m 2` nebo `/m #2`).

1. Vezmi číslo issue N.
2. Postupuj jako `Multiagent #N` dle `docs/multi-agent-workflow.md` a `.cursor/rules/multi-agenti.mdc`.
3. Podle labelu `ma/*` udělej jen aktuální fázi, zapiš do issue, posuň label.
4. Shrnutí + odkaz na issue.
